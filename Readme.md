# Pocket Ledger — Expense & Budget Visualizer

Aplikasi web mobile-friendly untuk mencatat pengeluaran harian, melihat sisa
saldo/anggaran, dan memantau distribusi belanja per kategori lewat pie chart.
Dibangun murni dengan **HTML, CSS, dan Vanilla JavaScript** — tanpa framework,
tanpa backend. Semua data tersimpan di **Local Storage** browser milikmu sendiri.

## Fitur

**Wajib (MVP)**
- Form input transaksi (Nama, Jumlah, Kategori) dengan validasi field kosong
- Daftar transaksi yang bisa di-scroll, lengkap dengan tombol hapus
- Total saldo/pengeluaran di bagian atas, otomatis update
- Pie chart distribusi pengeluaran per kategori (pakai Chart.js), otomatis update

**Tambahan (3 dari 5 opsi)**
1. **Kategori kustom** — tambah kategori baru sendiri lewat form, tersimpan permanen
2. **Sort transaksi** — urutkan berdasarkan terbaru, jumlah (naik/turun), atau kategori
3. **Dark/Light mode** — toggle tema, pilihan tersimpan otomatis
